These seven runtime hosts are isolated from production javac and owner files.
- ItemRenderer: only the two glint ResourceLocation constants consumed by actual official RenderType static initialization; avoids Item/Block registry bootstrap. No draw implementation.
- Entity, LivingEntity, Player, LocalPlayer: fixed position/yaw/pitch/eye-height/id/UUID and inheritance only for private ball/shield/diamond coordinate inputs. No gameplay, level, connection, admission or event behavior.
- Minecraft and Options: local-player identity and first-/third-person camera type selection only. No client/world/event/sound loop.
The owner-produced compileJava renderer and dependency ClassResources are bound and executed unchanged with these explicitly declared hosts. This formal entry compiles no production subject. Actual official Vec3, PoseStack, VertexConsumer default methods, RenderType creation, Camera rotation accessor, RenderLevelStageEvent camera accessor, Axis and JOML execute. A BufferSource subclass replaces GPU buffer allocation/flush with a VertexConsumer JDK Proxy recording positions, UV/RGBA and batch boundaries. No RenderType setup/clear, ShaderInstance, original engine, event ingress, GPU or audio executes. Same-port zero-camera executions are relocation controls, never original renderer oracles.
