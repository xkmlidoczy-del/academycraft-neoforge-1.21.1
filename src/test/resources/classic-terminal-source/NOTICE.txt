Harness and finite boundary stubs are newly written for this port under GPLv3.
They are test doubles, not a Minecraft, Forge, Guava, or LambdaLib runtime.
Unchanged original Java sources execute under javac/java without any mod launch.
MediaApp.scala is source evidence for the media_player ID and non-default state;
its Scala UI body is not executed, and the harness constructs a plain original
App with that exact source-defined ID. Client UI bodies are never invoked.

Original LambdaLib NBTS11n and SerializationHelper execute for terminal NBT
round trips. Their Minecraft tag classes, cache/reflection integration, and
logging are finite stubs. The original bitset is never passed to modern storage;
modern persistence is compared through semantic app-name projection.

No third-party music, album covers, or song-item artwork is included. Exact
excluded source paths and SHA256 values are in asset-inventory.json. Terminal
sound effects and UI images are separately identified non-song assets.
