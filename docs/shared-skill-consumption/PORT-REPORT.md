## Promotion contract

`docs/promotion-manifest.json` freezes additive files, original baselines, staged hashes, original baseline lane, artifact evidence and patch hash. `docs/integration.patch` contains narrow shared hunks only. `scripts/check_manifest.py` checks frozen bytes without writing production; `--targets` reports prerequisites or source drift. `scripts/verify_patch_replay.py` applies the patch only to isolated baseline copies.

Integrate the three prerequisite final lanes first. Copy only absent/identical additive files. Apply the shared hunks, retaining final-lane wiring, availability, client hooks and fixture additions. Do not copy entire old shared baselines over a merged target. For build.gradle, append the exact reviewed block in docs/build-gradle-additive-hunk.txt to the parent's current aggregate tasks. Re-run the parent's aggregate/headless checks and all relevant native fixtures after promotion, then validate physical client behavior. This worker never promotes or runs those lanes.
