## Gameplay retained

- DirectedBlastwave prepares then accepts release only at elapsed7..49 ticks; elapsed6/50 cancels, hold expires at200. CP160..200, damage10..25, probability.5..8, drop.4..9 and cooldown80..50 are captured Float source vals. Strain50..30 is read at perform. Four-block living/dragon-part ray uses LambdaLib inflated-hitbox and entity-feet-vs-block semantics. An empty ray uses caster feet+look*4; an entity uses its head. All other entity types whose feet are within radius3 are attempted without damage falloff. The source two-normalization delta uses overwritten y=-.4, scale-1.2, .1lift, then extra.24 impulse. Native damage rejection does not suppress hit classification, knockback or .0025EXP; no affected entity yields.0012EXP.
- Blast block center uses Scala math.round(Double).toInt with its negative half asymmetry. Loops are lower-inclusive/upper-exclusive center-3..center+2; squared distance<=6. Center needs no probability draw; successful candidate hardness0..2.9/25/55 at captured mastery<.25/<.5/otherwise then permission, then independent drop draw. Source block sound is deliberately absent. Air probes preserve chance ordering; unnecessary modern air updates/drops are skipped. Source unused effect_blocks message has no corresponding classic listener and introduces no invented debris.
- BloodRetrograde can release immediately, slows walk speed from.1 to.007 over20 ticks, automatically releases at30, and always restores classic.1 instead of prior custom speed. Server chooses a two-block living victim; block miss/occlusion and failed CP cancel without cost/EXP/cooldown. Damage30..60 is captured. CP280..350, strain55..40 and cooldown90..40 are dynamic at release. Attack precedes.002EXP; the original mastery-only achievement check is after award.
- StormWing is a toggle with empty key-up. Start grants mayfly while charging; end restores only the captured mayfly property as in source. Captured CP40..25, strain10..7, speed(.7 below.45 else1.2)*(2..3), and charge70..30 are Float expressions. Charge changes state only after stateTick>charge; transition is free, subsequent active ticks award.00005EXP before CP consumption, including the final failed-consume award. End cooldown30..10 is dynamic and integer-truncated; novice's first trained end can therefore be29. Each axis approaches expected velocity by at most.16. Directions are W/S/A/D, head yaw and pitch rotation, with the last pressed key owning direction; releasing that key clears it without falling back to another held key. No direction preserves horizontal velocity and adds.078Y unless a .5..-.3 block ray finds ground, when Y=.1. Fall distance is zeroed.
- Storm novice mastery<.15 probes40 random positions/tick, double offsets[-10,10) and truncation toward zero; nonair hardness0...3 blocks pass protection, disappear without drops, and play source break sound. Exactly mastery1 triggers range6 entity burst, including caster, with separate.9..1.2 axis draws and.5..1 magnitude. Ordinary GUI/preset flushes preserve this charged toggle and its source directional key group; explicit activation termination/lifecycle disposal ends it.

## Modern safety and transport

All entry points require server thread/alive/nonspectator, finite state and aim, canonical category/level/learned state and shared usable-resource gates. Input carries slot plus positive canonical long nonce. Client duration, damage, mastery, endpoint and victim IDs are never trusted. Directed/blood perform removes its hold before events and uses a committing fence. Repeated/stale nonce cannot spend or abort a newer context. Storm direction carries original authenticated slot, original context nonce and only index-1..3. That original slot remains the ownership anchor across preset changes, matching source persistent key group behavior. Native block hooks include source-style SkillBlockDestroyEvent plus modern BlockEvent.BreakEvent, loaded chunk/world border/global protection, and ordinary PvP/team gates before damaging/impulsing other players. Master burst may still affect its consenting caster.

Storm moves through the native collision resolver and authoritative ServerPlayer connection relocation. Ordinary FakePlayer teleport is a no-op; movement fixtures therefore use a real PlayerList-admitted ServerPlayer and official NeoForge mock Connection/EmbeddedChannel. Server-controlled motion replaces source client-controlled travel. Source air gravity/drag is applied after source velocity editing; 1.21 native collision/friction, vanilla player travel interaction, sustained movement latency and exact1.7 terrain motion remain native QA gaps. This is a deliberate transport adaptation, not a full motion-parity assertion. Nonfinite/unloaded endpoints fail closed. Clone/dimension/death/logout/server stopping restore owned permission/speed and dispose context; lifecycle discard does not add a cooldown to a replacement category.
