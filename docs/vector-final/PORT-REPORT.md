## Explicit modern differences and shared gaps

- All resource/progression/input/aim/destination changes are server-owned. Physical nonces, finite native data checks, identity/world checks, loaded chunks, per-world-time deduplication, context token tombstones, sequence order and queued scene/connection identity prevent replay or stale scene updates. Source client-side CP prediction is not allowed to grant server actions. In particular, forged early perform is denied by independently accumulated server duration
- Recursively reflected damage is bounded by a per-owner synchronous recursion fence; the original could recurse indefinitely between live reflectors
- NeoForge incoming damage is the current pre-mitigation mapping for legacy LivingHurtEvent. A negative pure remainder passes to the native damage pipeline; the current engine controls final no-damage behavior and never receives a custom healing operation
- Ownerless large-fireball reconstruction safely creates an ownerless replacement rather than reproducing the classic null-owner crash. Native fireballs retain modern scalar acceleration and projectile tracking. Legacy separate XYZ acceleration initialized from owner/source coordinates cannot be represented by an ordinary current vanilla fireball. Initial position/owner/power/speed/reflection direction are source-faithful; subsequent acceleration/inertia is modern vanilla behavior
- Current vanilla explosion propagation, damage mitigation, drops and audiovisual packets are used with source center/radius/phase gating; exact1.7.10 explosion physics and loot are not claimed. Native canceled explosion leaves the preceding explicit source attack intact
- Team/PvP and hanging entity damage guards, spawn protection and native block event cancellation are respected. Modern per-block permission checks may preserve blocks the classic global permission allowed. No unloaded chunks are generated for travel
- Shared CalcEvent.SkillPerform hooks, per-skill CP/overload/EXP/damage config multipliers, EntityAffection config extensibility, and the source triggerAchievement graph are still unported. Existing global damage/block/player options and common SkillAttackEvent are used. These gaps are not claimed solved here
- Native GameTests compiled, not executed by this lane. Real Developer screens/input/render pixels/audio remain unverified until parent execution
