# Teleporter progression fidelity ledger

## Exact scope and sources

Only PenetrateTeleport, MarkTeleport and FleshRipping from AcademyCraft classic1.0.7, pinned commit00d19ec0cf538f61c1095c9292f5ee6863db4521. Original TPSkillHelper, CatTeleporter, client entities/materials and LambdaLib1.2.3 Raytrace/Motion3D/RenderIcon/Particle/RandUtils/ContextManager are packaged as SHA256-checked test resources. Production and all original media remain untouched; integration is a narrow patch against frozen current snapshots. The common SkillAvailability registry continues deriving from PresetSkills. No parallel allowlist or target-mastery requirement was introduced.

## Source gameplay preserved

- PenetrateTeleport: level2; requires ThreateningTeleport learned with mastery>=.5; .8-block eye-origin scan, truncated integer coordinates, two noncolliding blocks, source three-stage traversal and fifth-clear-probe break, no backing up, stage0 available, stage1 unavailable; maximum10→35 and CP/block14→9. The loop advances once past the CP/range cap. Release uses current server aim/current mastery for endpoint but captured mastery for cost/cooldown; overload80→50, cooldown50→30, EXP=.00014F*float(distance). Crucially, unavailable calls terminate without return in the original: ContextManager marks disposed, so source execution still teleports into the unavailable endpoint. This is deliberately preserved, including CP force-flooring and full requested-cost training. No blocks are broken.
- MarkTeleport: level2; ThreateningTeleport learned mastery>=.4; server-held ticks, dist=min((ticks+1)*2,25→60,CP/(12→4)); normal block/entity trace. Block face offsets DOWN−1Y, UP+1.8Y, horizontal±.6 and blockY+1.7; horizontal non-air head check at trunc(x,y+1,z) lowers1.25. Entity endpoint is feet+eyeHeight. Distance<3 terminates free; successful release consumes source float distance*(12→4), overload40→20, cooldown30→0, EXP=.00018F*distance. No invented charge debit/timeout or automatic release.
- FleshRipping: level3; MarkTeleport learned mastery>=.5 AND PenetrateTeleport learned mastery>=.5. Captured mastery determines range6→14, CP130→270, overload60→50, armor-bypassing damage5→12, cooldown90→40 and hit EXP.005F. Held ticks check affordability without consuming CP and cache the latest server-traced living/boss-part target. Blocks occlude. Release attacks cached target; misses are free. Source TPSkillHelper independent sequential critical rolls/rates/passive EXP reuse the existing ThreateningTeleport canonical adapter. Mutable SkillAttackEvent/global damage scale and native protection/PvP/team/invulnerability hooks remain authoritative. Target selection still earns CP debit/EXP/cooldown if a native damage hook rejects the attack. Nausea has5% probability and100-tick duration on the CASTER. Creative mode skips CP/overload changes but trains requested costs, like source performWithForce.
- Teleports dismount, server-teleport once and reset fallDistance. Original persistent ac_tpcount increments for each Penetrate/Mark release. Ignore-barrier and400-teleport achievement facts are retained as player persistent flags. Critical hit has common-side and existing client-side cosmetic events.

## Necessary modern safety/transport adaptations and limits

- Player identity, dimension, state identity, level/category, activated/overload/interference/learned/cooldown gates, finite CP/aim/position and server thread are revalidated. Gameplay endpoints/duration/mastery/damage are never accepted from the client. Genuine preset slots carry canonical positive press nonces; release/abort must match. Duplicate/replayed/stale terminals and native callback reentry cannot commit twice. Per-world tick deduplication prevents repeated invocations from manufacturing charge ticks.
- Original contexts can dereference a null Flesh target before their first tick. The port initializes its cache from a bounded server trace on start, preserving normal first-tick gameplay and making immediate modern ingress safe. A removed/dimension-mismatched cached target aborts free rather than accessing a stale entity.
- Loaded-chunk, finite endpoint, world-border and build-height guards stop invalid teleports/traces. No chunk generation is requested. Modern collision shapes replace canCollideCheck, so blocks whose legacy collider behavior changed may differ. Source arithmetic and head-truncation quirks otherwise remain intact.
- LambdaLib's exact normalized1.7 lookup-table float direction is used via the existing common-only ClassicLateTrig. Modern ClassicRaytrace supplies the already-integrated source six-plane .3F inflated entity hitbox and source entity-feet/block comparison; contemporary entity/collision shapes remain native engine adaptations.
- Legacy remote-player +1.6 blood Y was a1.7 render-coordinate fix. Modern remote positions are already feet, so that fix is removed to keep blood attached to contemporary target bodies. Rendering uses current camera/matrices and framebuffer; no legacy GL/state reflection is performed.
- Source achievement-page prerequisites/icons/toasts are not newly invented as standalone native advancements: the original mastery parent chain includes future Flashing. The counter and invocation facts are retained, but complete classic achievement-page presentation remains a separate unported subsystem. This stage does not modify existing ThreateningTeleport achievement behavior or advertise that page as complete.
- Source generic CalcEvent.SkillPerform cost mutation is not yet a shared port API; these skills preserve source DEFAULT raw force-consumption curves within the existing shared double-valued CP model. No new skill-specific configurable consumption scaling is falsely claimed. The installed damage pipeline/config is honored.
- Modern packets add bounded nonce/UUID/world-epoch correlation. Cosmetic starts await authenticated acknowledgement; local release/abort hides the marker immediately. Remote cosmetic effects are shown to the initial25-block context audience, and stale world/connection/identity callbacks are dropped. This changes only transport timing, not server gameplay.
