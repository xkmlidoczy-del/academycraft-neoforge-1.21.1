# Classic Vector starter fidelity ledger

This increment implements only VecAccel and VecDeviation from AcademyCraft 1.0.7 commit 00d19ec0cf538f61c1095c9292f5ee6863db4521 with LambdaLib 1.2.3. The immutable source resources and licenses are bundled under classic-oracles/vector-starters. Original learning metadata remains in SkillCatalog; PresetSkills feeds the existing shared SkillAvailability and real machine menus.

VecAccel preserves the level-two DirectedShock prerequisite, captured 120→80 CP, dynamic 30→15 overload and 80→50 cooldown, strict mastery > .5 ground exemption, initially true tick-zero canPerform, two-block downward ground trace, and sine(.4 + clamp(ticks/20)*.6)*2.5 speed. Launch direction uses previous body rotation and pitch minus ten degrees. Release dismounts, changes native velocity, resets fall distance and earns .002F mastery. Abort and failed releases do not earn mastery. No teleport or invented minimum charge was added.

VecDeviation preserves its level-two VecAccel prerequisite, press-to-toggle behavior and persistence across key release, preset changes and ordinary delegate flushes. Explicit active-context termination and player/world lifecycle disposal end it. It preserves captured initial overload 80→50, separate captured tick CP 13→5 and dynamic normal CP 5→2.5 plus overload .5→.2, overload floor, and fixed force-consumed entity cost 15→12. Difficulty controls .001F*difficulty mastery only. Failed first debit marks deferred termination but still processes remaining entities and the second debit in that tick. Visited entities remain excluded on reentry; persistent ac_vm_deviated marks survive native NBT save/load. The original null-excluded WorldUtils query includes the caster, so self-stop, self-mark and one .001F award remain. The five-block filter uses entity feet, including exactly five and excluding AABB corners.

The first live deviation context globally reduces incoming damage to any player, rather than only its owner. Its owner pays min(CP, dynamic entity cost), earns damage*.0006F and the reduction .4→.9 is read after that award. Zero CP still reduces damage. Native protection cancellation remains authoritative. Arrows have damage zeroed and stop; large fireballs are discarded and use native explosion/protection hooks, small fireballs are discarded without explosion. Source excluded entity categories and projectile difficulty classification are retained.

VecAccel draws the original first-person 100-point parabola, drag-before-movement .98 integration and gravity 1.9*dt, source yaw rotation and negative-alpha tail before framebuffer clamping. Original vecmanip.vec_accel sound volume is .35. VecDeviation preserves source frame-Bernoulli HUD ripples, shader projection/UV/RGBA action, and original glow circle material and sound volume .5. Original stop-entity client code requires an already present client-side mark; legacy dimension/entity-ID serialization never synced server NBT. Accordingly the ring/sound guard remains dormant for newly server-marked client entities instead of inventing visible rings. Damage sound and active-context HUD remain separate original actions.

Modern adaptations: server authority validates identity, dimension, category, level, resources, finite aim, canonical preset slot and positive press nonce. Authenticated packets apply actual launch velocity; clients predict only cosmetic curves. Replays, stale terminals and world/connection callbacks cannot revive contexts or commit twice. Native contemporary entity classes/collision/damage/explosion APIs replace their legacy equivalents. The current shared double CP model and default source force-consumption curves are used; generic CalcEvent.SkillPerform cost mutation/config parity is still absent from the shared port. Achievement-page presentation, complete natural survival acquisition, GPU pixel parity and audible parity are not established by this stage.
