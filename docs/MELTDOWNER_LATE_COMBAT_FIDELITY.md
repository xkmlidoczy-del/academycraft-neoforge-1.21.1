## Modern security and movement adapters

No network request accepts aim, player identity, world, geometry, tick count, CP, damage, mastery or target IDs. Late skills require an authenticated physical slot nonce on wire start; Jet/Missile wire terminals additionally match that exact hold nonce. Legacy unnonced slot requests cannot bypass these fences. Internal trusted APIs retain nonce0 for native fixture/server calls. Replay histories retire successful starts; all server work is server-thread-only and validates alive/nonremoved/nonspectator player, finite resources/aim/position, state identity, category/level/learned skill and world identity. World-time guards prevent duplicate ticks; commit/tick fences prevent native event reentry.

Jet deliberately moves on the server rather than trusting original client setPosition/movement packets. It sends native teleports for the source finite trajectory, applies source velocity/fall reset, temporarily disables gravity and restores the previously owned noGravity value on every termination/lifecycle path. Source block tunneling remains; new steps refuse unloaded chunks or world-border exit. Collision damage is computed from each authoritative segment, rather than relying on timing of the old client's movement packet relative to server lastTickPos. This ordering is an explicit modern transport adaptation; exact native physics/packet/anticheat behavior awaits the main runtime lane. No flying entitlement or walk attribute is created. Local cosmetic walk speed uses the literal source .07/.1 values.

Normal native damage/config/NeoForge events apply, including mutable SkillAttackEvent, incoming damage, PvP permission, armor and invulnerability. MD radiation marking reuses the existing original helper and preserves originating skill IDs. No additional explosion/block damage/projectile alias is introduced.
