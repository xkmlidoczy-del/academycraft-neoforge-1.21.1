# Classic media player boundary

Baseline: AcademyCraft **1.0.7**, commit `00d19ec0cf538f61c1095c9292f5ee6863db4521`, with LambdaLib **1.2.3**. Source witnesses are byte-preserved and hash-pinned under `src/test/resources/classic-oracles/terminal-media`; the original README, GPL text and LambdaLib MIT license accompany them. This increment restores the classic terminal media app for **local user-provided audio**. Internal songs, original song covers and song-item artwork are deliberately excluded. There is no internal media registry, copied track config, song acquisition item, fake unlock, download or substitute song.

## Runtime retained

`cn.academy.port.client.terminal.media.ClassicMediaClient.openScreen()` implements the original `MediaApp.onStart` entry. Client-only automatic event subscribers own playback ticks, shader registration and the media mini-HUD. Common terminal code must call this entry only through its client adapter; it must not reference client classes on a dedicated server.

The library discovers lowercase `acmedia/source/*.ogg` under the actual Minecraft game directory. The classic ID remains the filename prefix **before the first dot**. Each external track is immediately available, matching `MediaAcquireData.isInstalled`: external tracks do not require player acquisition bits. The `<id>_name` and `<id>_desc` properties default to the ID, as the source did, and can be edited with the two original pencil controls. Enter, focus loss, screen close and resize commit editing to local UTF-8 `acmedia/metadata.properties`; volume changes also save immediately. A user README is preserved; this port creates an explanatory README only when absent.

Clicking a row starts that track. Play/pause pauses or resumes the current native source; from idle it replays the last track or chooses the first external track. Stop removes current-playing state but retains the last track until the local player is reset. Closing the screen retains playback and exposes the mini-HUD, including while paused. Natural native EOF removes current-playing state; it does not loop or advance a playlist. Both time labels retain source integer truncation, minute/second division and two-character minimum padding. Vanilla music is stopped every five local client ticks only while media is actively playing.

Original main/player-aux XML, background, play/pause/stop, volume overlay, pencil and missing-cover assets are preserved byte-for-byte. Main geometry uses the source 650×504 panel and 0.32 scale, centered with fitting only for very small windows. Rows preserve original 554×60 dimensions inside the 552×302 list, five complete visible rows, zero row X and 60-unit spacing. Scroll progress remains a discrete first-row index. Source default mini-HUD is 145×36, right/bottom aligned with -6 offsets; its 500 ms refresh, title, time and progress presentation are retained. `ClassicHudConfig.MEDIA_X/Y` preserve those right/bottom offsets. `hudPosition`, `setHudPosition` and `renderHudPreview` expose real position/editing/preview to the terminal's HUD customization registry. System font preference and original CJK fallback sequence use existing `ClassicHudConfig.FONT`; no font file is bundled.

## Modern audio ownership

Minecraft 1.21.1's official **JOrbisAudioStream** decoder performs actual Vorbis header validation and streamed PCM decoding. The player acquires a STREAMING channel through the existing sound engine's **ChannelAccess** and existing OpenAL context. It never creates a second sound library, Java Sound playback device, mock timer, subprocess player, or separate native context. All channel attachment, playback, pause, resume, gain changes and stopping run on the existing sound executor. The source reflected its legacy sound-system/library ownership; the narrow modern bridge pins official `SoundManager.soundEngine`, `SoundEngine.channelAccess/loaded` and `Channel.source` fields, which the headless API-shape check verifies without initializing them.

Timing combines actual decoded PCM buffer durations with native `AL_SEC_OFFSET`; consumed buffers are counted as OpenAL unqueues them. It is not advanced by game ticks, screen frames or a wall-clock estimate. Gain is applied through actual native `Channel.setVolume`. Mono/stereo audio is listener-relative, non-looping and unattenuated, matching the classic source's playback intent. Minecraft's shared listener/master volume still applies.

An asynchronous request token rejects old decode and channel-allocation callbacks after replacement, stop, logout or audio reload. An unattached decoder is tracked and closed on cancellation, even if sound-executor flushing drops a pending channel-allocation task. Attached decoders belong to the channel and close when it is released. Stopping and stale callbacks schedule the owning `ChannelAccess` cleanup immediately after native stop. Official `SoundEngine.tick(boolean)` also schedules channel cleanup while paused; official sound-engine reload/destroy clears and releases handles. Logout/player-clone adapters reset transient playback and last-played state. Audio-device/resource reload cancels playback through `SoundEngineLoadEvent`. A changed/removed/replaced audio file, source directory or acmedia directory stops playback at the next five-tick observation and reports the change.

## Explicit adaptations

- No internal tracks or internal acquisition progress exist; the external library is the complete playable media catalog
- Library order is deterministic by filename. Duplicate classic IDs select the first valid filename and report others; legacy unordered file enumeration could expose duplicate rows and a later map override
- Local files/directories may not be symlinks, and source/cover ancestors are rechecked at use. The strict framing reader validates Ogg checksums, continuous pages, Vorbis identification and a final granule. Single logical-stream, mono/stereo Vorbis at 8–192 kHz and audio files up to 512 MiB are supported. Chained/multiplexed, empty, malformed or unsupported streams are reported, with actual decoder-header validation before display
- Safe optional user PNG covers are bounded to 16 MiB and 2048×2048. Missing, unsafe or undecodable covers use the original missing-cover icon. Cover textures belong to the screen and are released on close/refresh
- Local metadata is bounded to 1 MiB and edited fields to 2048 characters, and writes use atomic replacement when supported. Font glyph caches are bounded, and long labels are fitted to their original boxes
- Native floating-point time/progress uses modern queue/sample observations; no equal waveform, exact legacy decoder rounding or renderer-pixel equivalence is claimed
- F5 library refresh, Space play/pause, arrow/wheel list navigation, empty-library instructions and explicit error messages are modern accessibility/diagnostic additions. The source XML remains byte-exact

## Evidence and acceptance

`MediaRegressionTest` runs from a packaged artifact in an unrelated temporary working directory. It pins source/resource bytes; independently checks source filename/default metadata/external availability/time/layout boundaries; compiles and executes **unchanged LambdaLib ElementList.java** in a JDK-only classloader with finite widget-ownership shims; and checks local settings restart persistence, framing/CRC/EOF/sequence rejection, duplicate IDs, covers, symlink/ancestor replacement rejection, stale request cancellation, pause/resume/stop/reset and variable PCM queue durations through EOF. Framing fixtures are synthetic identification/granule boundaries, **not playable music**, and are not represented as decoder/audio acceptance.

`MediaNativeApiShapeTest` and all production/test classes compile against cached official NeoForge **21.1.252 / Minecraft 1.21.1** APIs. The optional `MediaNativePlaybackFixture.start(Path)` accepts an existing authorized user source inside the actual client's `acmedia/source`, adds its client-tick listener only after explicit invocation, and has a finite 240-client-tick timeout. With a real player/audio device and a sufficiently long user source, it checks actual native playing state, native `AL_GAIN=.25`, frozen paused sample time, resumed time, a second pause followed by stop, and **awaits native channel release** before success. It restores the prior volume and unregisters its listener on success/failure. It is in `src/test/java`, has no GameTest holder or automatic native-suite registration, and is never started by the headless tests.

The isolated script is `.staging/terminal-apps/media-worker/scripts/verify-stage.py`. It reads the client owner's actual proposed `ClassicHudConfig` as a recorded compile input and writes only this media staging tree. **No Gradle, native client, audio device, game server, desktop UI, screenshots, service, push, publish or EULA operation has been performed.** Native audio acceptance, interrupted allocation/reload stress, visual comparison and a real local media playback session remain the integration owner's serial acceptance work. Headless source/transport checks do not prove those live behaviors.
