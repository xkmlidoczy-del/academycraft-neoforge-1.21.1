- Settings retains source742×923 art at0.2 scale, checkbox/key/category/callback rows and scrolling. PvP and destruction use the actual AcademyConfig values and appear only for the integrated server. Ground/first-person/third-person contexts use the unmodified original terminal_installer OBJ and texture because source `renderEntityItem=true`. The OBJ has47 positions,48 UVs,37 declared normals and72 triangles. Existing verified Forge Wavefront UV inset/flat-normal parsing and double-sided translucent mesh emission are reused.

Reloads replace or clear the mesh rather than retaining stale resource-pack data.
