# Classic Cat Engine, creative presentation and hidden display items

Private isolated source port for AcademyCraft **1.0.7**, requested commit `00d19ec0cf538f61c1095c9292f5ee6863db4521`, LambdaLib **1.2.3**, Minecraft **1.21.1**, NeoForge **21.1.252**. Cached original sources are authoritative; independent Git metadata is unavailable. Nothing here asserts a 1.7.10 world importer, natural survival acquisition, actual client acceptance, external publication or unrestricted redistribution.

| `ModuleEnergy.infiniteGen`, `academy-craft:ac_Block_infiniteGen` | `academy:cat_engine` block/item/tile | Genuine creative-tab power device and ordinary block recovery drop; **no survival recipe**, fuel or GUI |
| `AcademyCraft.logo`, `academy-craft:ac_Item_logo` | `academy:logo` | Plain `Item` with the `academy:logo` bitmap; **no creative contents, recipe or behavior**; icon of the dedicated `AcademyCraft` tab |

`cat_engine` is the source block name; `infinite_generator` is its zero-slot inventory name. They identify one device. No second generator was invented. The modern Cat has no item-handler, fluid, FE, fuel, menu or battery-charging capability. Native IF is its actual existing wireless generator interface. The source default block hardness is zero, full-cell collision and nonopaque rendering are retained.

## Cat arithmetic, native lifecycle and interaction

Source `TileCatEngine` delegates to `TileGeneratorBase`: buffer2000IF; bandwidth200IF; every loaded server tick sets `thisTickGen = min(required,500)` and adds exactly that to the buffer. Four ticks fill an empty unlinked Cat. A full Cat generates0. `getProvidedEnergy` directly returns `min(request,energy)`; the native graph applies200IF input bandwidth. The tile itself does not invent a second bandwidth cap. Source energy and generation-speed messages run every20ticks after generation, within radius20.

The real block's right-click is consumed on both sides, including sneaking and when holding an item. Server click unlinks an already-linked generator. Otherwise it searches the existing graph's source20block/max100 eligible nodes, chooses one with world randomness, sends the original localized message and links with **needAuth=false**, as the original two-argument `LinkUserEvent` does. Passworded eligible nodes can therefore receive this source creative device. Empty/full/unloaded/out-of-node-range nodes do not create a connection. No frequency GUI or invented password prompt exists. Normal source native placement/use admission supplies the interaction route; no custom packet expands access.

The generator capability is live only for the actual current loaded server tile, never a replaced/removed/client object. Removing the Cat unlinks it immediately. Source graph semantics and previously declared graph conservation corrections remain those of the existing `ClassicWirelessGraph`; this stage does not replace or alter that graph.

Explicit modern adaptations: malformed/nonfinite/negative requests and save values are admitted finitely; actual native IF energy is serialized, fixing the source `TileGeneratorBase` energy-NBT omission; new chunks receive generation/energy presentation with their native block-entity update; modern block updates use host tracking instead of a bespoke radius20 legacy packet; removed/replaced objects cannot continue supplying power; block removal eagerly clears its graph link. Transient generation, clocks and rotation are reset rather than persisted. These are lifecycle/transport corrections, not source survival features.

## Original visible presentation

Original unchanged `textures/blocks/cat_engine.png` and `textures/items/logo.png` are32x32RGBA. `textures/null.png` is23x23RGBA with every alpha0. Runtime bitmaps are compared byte-for-byte and pixel-for-pixel to independently packaged original witnesses. The block's baked world model is empty; the real Dist.CLIENT renderer emits the source one-unit four-vertex plane with disabled face culling, original UV order, source camera-relative yaw `atan2(x+.5,z+.5)+180`, Y bob `.03*sin(time*.006)`, and pitch accumulation `(now-lastRender)*generation*.01`, modulo360. Original captured GL calls and coordinates are differential-tested. Source `RenderEmptyBlock.shouldRender3DInInventory=false` gives its item a flat original cat icon. No OBJ, extra faces, new animation or GUI is introduced.

Modern native entity buffers/cutout, packed light and host camera matrices replace immediate OpenGL. The existing pause-aware common client clock supplies time; its origin differs from the old absolute GameTimer, so sine phase is a declared clock-origin adaptation. Source geometry, amplitudes, rates, generation dependency and pause behavior remain. A weak client-only map replaces intrusive tile rotation fields and releases removed tiles. Actual visible orientation/UV/lighting/reload/pause acceptance remains with the owner.

## Hidden dummy and achievement catalog bridge

Source `ItemAchievement` assigns a process-local metadata index for each texture and reserves index0 for `academy:textures/null.png`; identical resources reuse the index. The modern equivalent stores the exact resource in native `CUSTOM_DATA` under `academy_achievement_texture`. This produces stable stack identity and native codec/save/network behavior without a process-local index that could change across launches. Default/malformed payloads choose the original invisible null texture. Valid resource-pack texture locations remain dynamic. Source inventory-only rendering and source-alpha blending are retained through the dedicated GUI renderer; no item in hand/on-ground render or new reward is promised.

`ClassicDisplayItems.forIcon(String)` accepts the **existing frozen achievement catalog's unchanged `texture:`/`item:` descriptor**. Texture descriptors create the one real hidden `achievement_icon` stack; ordinary item descriptors resolve the original registered item. The separately guarded achievement bridge changes only its bitmap branch to `g.renderItem(ClassicDisplayItems.forIcon(e.icon()),x,y)`. Its page positions, frames, award IDs and ordinary item branches remain intact. That dependent hunk must be applied after the achievement stage is promoted and checked against that stage's exact original Visual SHA. No second icon registry or catalog/page/award implementation is introduced.

## Dedicated creative tab

`academy:academycraft` has original `itemGroup.AcademyCraft` title in all four existing locales and the original hidden logo as its real icon. The explicit source-declaration membership catalog includes every genuinely registered classic equivalent and the three generated source app installers. Optional/staged RF/Hook/Interferer entries are skipped until their real registry keys exist; unsupported conditional IC2 and intentionally excluded song-specific items remain excluded. There are no placeholder AIR entries.

Source variant presentation is retained: depleted then fully charged portable developer and energy unit; four native induction factors; three native matrix-core registry variants; empty and phase-filled matter units. Each tab entry has count1. Source `logo` and `DUMMY_ITEM` are hidden from contents. The tab also appears in host creative search normally. Existing ordinary vanilla-tab placements stay present as a host compatibility choice; source dedicated membership is now restored. Ordering uses the source field declaration inventory rather than unstable old annotation-reflection order. The host native tab frame/scroll/search are a deliberate modern presentation adaptation.

## Verification and acceptance boundary

The stage verifier assembles current main plus this additive payload and guarded shared hunks in a disposable isolated root with no `.reference` or `.staging`. It uses only the cached JDK and official Minecraft/NeoForge API artifacts. Every production/client/native-fixture source compiles. Three standalone suites cover independently compiled unchanged original Cat/link/render/icon methods, actual unchanged modern wireless graph with client-denied common-class linking, byte-exact source pixels/four locales and native resource/layout contracts. Packaged witnesses retain GPLv3/README additional restrictions and LambdaLib MIT. Tests work in a clean archived root.

Seven ordinary native fixtures compile and are **not run here**: `classic_cat_native_identity_collision_capability_and_no_fuel_inventory`; `classic_cat_native_source_right_click_random_node_no_auth_shift_and_unlink`; `classic_cat_native_save_reload_old_capability_and_removal_graph`; `classic_cat_native_twenty_tick_packet_energy_generation_and_no_inventory`; `classic_hidden_icon_native_component_roundtrip_fallback_and_catalog_adapter`; `classic_creative_native_tab_logo_hidden_items_and_source_variants`; `classic_creative_only_cat_native_drop_and_no_invented_acquisition`.
